# Evaluator Rubric

Score each dimension 0–2 and cite repository evidence. A self-score cannot satisfy `independent-review`.

| Dimension | Question | Score | Evidence |
|---|---|---:|---|
| Correctness | Does behavior match the feature contract? | | |
| Verification | Did every required profile actually run with current evidence? | | |
| Scope discipline | Were changes confined to the declared surface or explicitly re-scoped first? | | |
| Reliability | Does the result survive restart and rerun? | | |
| Maintainability | Can another agent understand boundaries and commands, including the DRY/SOLID/YAGNI assessment and evidence? | | |
| Handoff readiness | Can a fresh session continue from repository artifacts only? | | |

Verdict: Accept / Revise / Block
